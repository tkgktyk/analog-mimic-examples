# 6 章 信号源と変調

入力がなくても信号を作る回路(発振器、雑音源、定電圧源)と、信号で搬送波を変える回路(変調器)です。入力の電圧で周波数、振幅、パルスの幅を変えることで、アナログの電圧をほかの形に「乗せかえる」ことができます。

| | 講義 | 内容 |
|---|---|---|
| 6-1 | [発振器と定電圧](01_oscillator.ipynb) | 関数発生器、4 つの波形、周波数の正確さ(時計)、定電圧源 |
| 6-2 | [VCO(電圧制御発振器)](02_vco.ipynb) | 入力の電圧と周波数、周波数変調(FM)、0 Hz で止まる |
| 6-3 | [ノイズ(雑音)](03_noise.ipynb) | 白色雑音とピンク雑音、電圧の分布と実効値、スペクトル、出力のフィルタ |
| 6-4 | [AM とリング変調](04_modulator.ipynb) | 包絡線と変調度、側帯波、過変調、チョッパ |
| 6-5 | [PWM と V/F 変換](05_pwm_vf.ipynb) | デューティ比、平均して D/A 変換、三角波とのこぎり波、電圧を周波数に |
