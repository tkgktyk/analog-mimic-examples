# 2 章 1 次フィルタ

抵抗とコンデンサ 1 個ずつで作るフィルタです。周波数によって信号の通しやすさや位相が変わる、いちばん基本のフィルタを扱います。

| | 講義 | 内容 |
|---|---|---|
| 2-1 | [1 次のローパスフィルタ(LPF)](01_lpf.ipynb) | 正弦波の振幅と位相、方形波のなまりと時定数 |
| 2-2 | [1 次のハイパスフィルタ(HPF)](02_hpf.ipynb) | 位相の進み、方形波の跳ねと時定数、直流のずれの除去 |
| 2-3 | [周波数特性を測る(ボード線図)](03_bode.ipynb) | ボード線図の測り方、デシベル、遅れと位相 |
| 2-4 | [1 次のオールパスフィルタ(APF)](04_apf.ipynb) | 振幅を変えずに位相だけを変える |
