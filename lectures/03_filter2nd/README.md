# 3 章 2 次フィルタ

コンデンサを 2 個使う(またはそれに相当する)フィルタです。1 次のフィルタより急に周波数を切り分け(40 dB/decade)、**Q** で $f_c$ の近くの形を変えられます。最後に、これらをまとめて作れる状態変数フィルタを扱います(Mimic の 2 次のフィルタの中身です)。

| | 講義 | 内容 |
|---|---|---|
| 3-1 | [2 次のローパスフィルタ(サレン・キー)](01_sk_lpf.ipynb) | Q の意味、$f_c$ でのゲイン、方形波の行き過ぎと振動 |
| 3-2 | [2 次のハイパスフィルタ(サレン・キー)](02_sk_hpf.ipynb) | Q を変えたボード線図、1 次と 2 次の比較 |
| 3-3 | [バンドパスフィルタ(多重帰還)](03_mfb_bpf.ipynb) | 帯域幅 $f_c/Q$、方形波から正弦波を取り出す |
| 3-4 | [ノッチフィルタ(ツイン T)](04_notch.ipynb) | 決まった周波数を消す、方形波から基本の周波数を除く |
| 3-5 | [状態変数フィルタ](05_svf.ipynb) | 4 種類の出力、足すと入力に戻る |
