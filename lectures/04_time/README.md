# 4 章 時間の処理

入力を時間で積み上げる(積分)、入力の変化の速さを出す(微分)回路と、時間にかかわるそのほかの処理(ある瞬間の値を保つ、変化の速さを制限する、遅らせる)です。2 章の LPF と HPF は、周波数によっては積分器と微分器のように働きます。3 章の状態変数フィルタも、積分器を組み合わせたものでした。

| | 講義 | 内容 |
|---|---|---|
| 4-1 | [積分器](01_integrator.ipynb) | 直流を積分する、リーク、方形波を三角波に、ボード線図 |
| 4-2 | [微分器](02_differentiator.ipynb) | 三角波を方形波に、方形波のとげ、雑音と制限、ボード線図 |
| 4-3 | [サンプル&ホールド](03_sample_hold.ipynb) | 階段の出力、トラック&ホールド、エイリアシングとサンプリング定理 |
| 4-4 | [スルーレート](04_slew_rate.ipynb) | 方形波の縁の傾き、正弦波のゆがみ、振幅で変わるフルパワー帯域幅 |
| 4-5 | [遅延(むだ時間)](05_delay.ipynb) | バケツリレー素子、1 周期より長い遅れ、位相が周波数に比例するボード線図 |
