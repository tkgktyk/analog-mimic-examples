# 7 章 演算する回路

電圧どうしの「計算」をする回路です。対数をとる、2 乗する、平方根をとる、平均するといった計算を、ダイオードやトランジスタ、アナログの乗算器で行います。何桁にもわたる信号を 1 つの目盛りに収めたり、電力や実効値を求めたりできます。

| | 講義 | 内容 |
|---|---|---|
| 7-1 | [対数アンプと逆対数アンプ](01_log.ipynb) | 入力が 10 倍で出力が一定だけ変わる、圧縮、1 V/oct |
| 7-2 | [二乗回路と平方根回路](02_square.ipynb) | 乗算器、周波数が 2 倍になる、電力、差圧から流量 |
| 7-3 | [実効値(True RMS)](03_rms.ipynb) | 2 乗の平均の平方根、平均値方式との差、時定数とリプル、AC+DC |

ANTILOG、二乗回路、平方根回路、True RMS の出力は、Vref ではなく **0 V からの大きさ**です。不感帯(デッドゾーン)は [5-3 クリッパ](../05_nonlinear/03_clipper.ipynb) の最後にあります。
