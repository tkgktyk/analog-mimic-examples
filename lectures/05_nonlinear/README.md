# 5 章 非線形の回路

出力が入力に比例しない回路です。しきい値で HIGH / LOW を決める(比較器)、範囲の外を切り取る(クリッパ)、向きをそろえる(整流)、山を覚える(ピークホールド)といった働きは、ダイオードや、帰還をかけないオペアンプで作ります。周波数特性(ボード線図)の代わりに、**入出力特性**(入力の電圧を横軸、出力の電圧を縦軸にしたグラフ)で見ます。

| | 講義 | 内容 |
|---|---|---|
| 5-1 | [比較器とシュミットトリガ](01_comparator.ipynb) | 正弦波を方形波に、チャタリング、ヒステリシス |
| 5-2 | [ウィンドウ比較器](02_window.ipynb) | 窓の外にいる時間、入出力特性 |
| 5-3 | [クリッパ](03_clipper.ipynb) | ハードとソフト、高調波(ひずみ)、三角波から正弦波、不感帯 |
| 5-4 | [整流回路](04_rectifier.ipynb) | 精密半波整流・全波整流、平均値で交流を測る |
| 5-5 | [ピークホールドとエンベロープ](05_peak_envelope.ipynb) | 山を覚える、リセット、放電、時定数とリプル |
